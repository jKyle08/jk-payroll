# Task Execution Rules for AI Agents

Status: `IMPLEMENTED`

## 1. Rules Before Making Changes
1. **Audit First:** Inspect existing source code before assuming missing features.
2. **Never Break Tests:** Always run `npm test` before and after changes.
3. **Never Weaken Security:** Never relax RBAC guards or bypass multi-tenant scoping.
4. **Preserve Compatibility:** Maintain backward-compatibility route aliases.
