# UI/UX & Design System Standards

Status: `IMPLEMENTED`

## 1. Design System Rules
- **Color Palette:** Slate/neutral backgrounds (`bg-slate-50 dark:bg-slate-950`), vibrant primary blue accents (`bg-blue-600`), and semantic status colors (green for Active, red for Suspended/Denied).
- **Typography:** Inter for user interface prose; JetBrains Mono for codes, slugs, tokens, and IDs.
- **Header Standard:** Clean Facebook-style topbar with strictly two right-hand action targets (Notification Bell and User Avatar).
